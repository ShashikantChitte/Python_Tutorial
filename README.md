## How to use

1. **Read on GitHub** – open any lesson; code and output are shown together.
2. **Run it yourself** – copy the code blocks into VS Code or JupyterLab (Python 3).
3. Code that calls `input()` asks you to type an answer.

Requirements: **Python 3.10 or newer** (the `match` statement). Nothing else is needed for lessons 01–09. Some Practice Codes topics use extra packages; each file says which.

The *Modules and Packages* lessons create their own small example files, so nothing else has to be kept next to them.

> The outputs shown in the lessons were generated by running the code with Python 3.12. Memory addresses and similar details can differ on your machine.
